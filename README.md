# Returns & Refunds Analytics Project

## Project Overview

The **Returns & Refunds Analytics Project** analyzes product returns, refunds, and reverse-logistics costs to understand their impact on marketplace profitability. Using SQL, Excel, and Power BI, the project identifies key return drivers, evaluates category-level economics, and models potential margin recovery from targeted interventions.

## Business Problem

High product returns can increase refund outflows and reverse-logistics costs while reducing net contribution. The business needs to understand which categories, return reasons, customers, and sellers contribute disproportionately to returns and which interventions may improve profitability.

## Objectives

-   Measure return rate, refund leakage, reverse-logistics cost, and net contribution by category.
-   Identify the most common return reasons using Pareto analysis.
-   Find customer, seller, and product cohorts associated with high  return activity.
-   Evaluate policy differences and their economic implications.
-   Model a ₹20 crore intervention budget and estimate potential margin recovery under scenario assumptions.

## Tools & Technologies

-   **SQL** --- data querying, segmentation, and analytical calculations.
-   **Microsoft Excel** --- data cleaning, preprocessing, and  exploratory analysis.
-   **Power BI** --- interactive dashboards, KPI monitoring, and visual  analysis.

## Work Performed

1.  Cleaned and prepared the data in Excel for analysis.
2.  Used SQL queries to analyze return patterns and identify high-return customer and seller cohorts.
3.  Calculated and reviewed business metrics such as return rate, refund leakage, reverse-logistics cost, and net contribution.
4.  Conducted return-reason Pareto analysis to identify the reasons contributing most to returns.
5.  Built Power BI dashboards to communicate category performance,  return drivers, and profitability insights.
6.  Developed a ₹20 crore intervention simulator to compare potential return-reduction strategies and estimate expected margin recovery based on scenario assumptions.

## Key Business Questions

-   Which product categories have the highest return rates and return-related costs?
-   Which return reasons account for the largest share of returns?
-   Which customer and seller cohorts contribute disproportionately to  returns?
-   How do return policies affect costs and net contribution?
-   How could a ₹20 crore intervention budget be allocated to improve margin recovery?

## Expected Outcomes

-   Clear visibility into return and refund performance across categories.
-   Identification of major return drivers and high-risk cohorts.
-   Better understanding of the cost and contribution impact of returns.
-   Scenario-based estimates to support intervention prioritization and budget allocation.

## Project Deliverables

-   Excel data cleaning and analysis.
-   SQL queries for return and refund analytics.
-   Power BI dashboards for KPI tracking and business insights.
-   ₹20 crore intervention scenario simulator.
